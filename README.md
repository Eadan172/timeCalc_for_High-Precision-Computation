# 分子模拟运行时间估算

根据体系规模（氨基酸残基数、配体原子数等）与硬件档位（GPU / CPU 线程），估算 GROMACS 一类 MD 的墙钟时间。

## 使用方法

1. 安装 Python 3（需带 tkinter，Windows 官方安装一般已包含）
2. 双击 `run.bat`，或在本目录执行：

```bat
py -3 md_time_calc.py
```

3. 在界面中填写残基数、配体原子数、模拟时长、GPU 等，点击「估算」

## 说明

- 当前内置参考基准来自一次约 2.5 万原子、消费级 Laptop GPU、全 GPU offload 的校准跑，**不绑定具体机器路径或主机名**
- 换机器或换设置后，建议用短跑（如 `-nsteps 20000`）读 log 中的 `ns/day`，再更新脚本顶部的 `P0` / `N0` / `OMP0`
- 立项排期建议保留安全系数 `S ≈ 0.7`
